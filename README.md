# 3D 互动科学课件工具包（清透实验室风格）

**一句话**：用「铜匠实验室」54 门高中科学 3D 课件总结出的完整方法，做出同样质量的互动课件——
**一个 HTML 文件，双击就能打开，断网也能上课，投影和电子白板都可用。**

这是一个 [Agent Skill](https://code.claude.com/docs/en/skills)（也可以当普通模板用）：既能让人照着做，也能让 AI 编程助手（ZCode / Claude Code 等）加载后按同样的标准产出课件。

---

## 能做出什么样的课件？

每一门课件都是一个 3D「虚拟实验台」：

- 🧊 **3D 场景**（three.js）：实验台、器材、工业流程、地貌沙盘……可自由环绕、拉近拉远
- 📋 **步骤条 + 中控台**：老师按「下一步」从头讲到尾；右侧仪表盘的滑杆、开关与 3D 画面联动
- ❓ **主线问题驱动**：顶栏常驻一个学生真正关心的问题（例：「一块银白色的小金属，为什么着火时连水都不能浇？」）
- ✋ **每步动手**：学生必须完成一个操作（拖滑杆/开开关/记录数据）才能解锁结论
- 🎯 **考核关**：保持某个目标 15 秒才算过，**中途还会出突发状况**（「有人把灭火器换成了水……」）
- 📝 **随堂检测**：选择题的每个错误选项都是真实的学生迷思概念，答错可跳回对应章节

适用学科：**物理 / 化学 / 生物 / 地理 / 数学**（初高中均可）。

## 三步做一门课件

```bash
# 1. 复制模板
cp -r assets/starter/  我的课件/
cd 我的课件/
npm install

# 2. 写内容（照着示例课写四块：内容 C / 3D 世界 world / 仿真模型 model / 中控台 console）
#    打开 src/course/course.demo.js 照抄结构即可

# 3. 构建
node build.js     # 产出 dist/<课件名>.html —— 双击即用
```

不想装 Node？把课件内容按 `references/architecture.md` 的约定手写进一个 HTML 也行（three.js 在模板的 node_modules 里就有，离线可用）。

## 给 AI 编程助手用

把整个 `3d-courseware/` 目录放到技能目录（`~/.agents/skills/` 或项目的 `.agents/skills/`），
然后对 AI 说「**帮我做一门 XX 课件**」即可。AI 会自动按以下流程工作：

1. **教学设计**（先内容后代码）：主线问题 → 知识链 → 7–9 个步骤 → 每步「动手-观察-结论-考点-易错点防护」五件套
2. **搭建**：复制 starter 模板，写 `C / world / model / console` 四块
3. **验收**：运行时用内置调试 API `window.__lab` 核对每个数字、跑通考核流程

配套文档都在 `references/`：教学方法论、架构契约、学科差异化模式、视觉规范，以及三份真实课件的 C 对象范例。

## 目录结构

```
3d-courseware/
├── SKILL.md                 # AI 技能入口（工作流 + 验收红线）
├── references/
│   ├── pedagogy.md          # 教学设计方法论（这套课件的内容内核）
│   ├── architecture.md      # 四块架构契约与字段手册
│   ├── subjects.md          # 物理/化学/生物/地理 各自的场景骨架与特效手法
│   ├── visual-spec.md       # 「清透实验室」视觉规范（玻璃拟态 UI + 3D 质感）
│   └── exemplars/           # 三份真实课件的内容对象范例（可读中文版）
└── assets/
    ├── step-shell.css       # 界面设计系统原件
    └── starter/             # ⭐ 可运行模板（three + esbuild 已配好）
        ├── build.js         # 一键打包成单文件 HTML
        └── src/
            ├── framework/   # 步骤引擎、界面外壳、3D 基建（所有课件共用）
            └── course/      # 单摆示例课（照着写你的课）
```

## 示例课件

`assets/starter/dist/pendulum-demo.html` —— **单摆：为什么摆能数时间**（8 步完整流程，含考核与检测，双击打开即玩）。

用这套工具已实际制作：《总统证法：用一把梯形证明勾股定理》（数学史 × 勾股定理，1876 年加菲尔德的梯形证法）。

## 课件质量红线（这套方法的灵魂）

- 每一步必有五件套：**驱动问题 → 动手任务 → 带具体数字的观察清单 → 教材原话结论 → 「去掉这一步学生会……」的迷思概念防护**
- 所有 expect 数字必须与仿真公式一致（不许写一个算不出来的数）
- 考核没有新知识：考「会不会用前面所有的开关与读数」，且有中途突发事件
- 每个读数都标注依据（教材页码 / 按公式计算 / 课件设定）

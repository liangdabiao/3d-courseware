# 学科差异化模式（物 / 化 / 生 / 地）

> 来源：对喀斯特、河流地貌、神经冲动、酶活性、大气热力环流、金属钠、合成氨、光电效应
> 8 门课的逐行分析。**学科差异全部体现在 C/world/model/console 四块的内容里，而不是结构里**
> —— 四块契约对每门课都一样（见 architecture.md）。

## 0. 第一个决定：知识链的性质 → 场景骨架

| 知识链性质 | 典型学科 | 场景骨架 | 主 slider |
|---|---|---|---|
| **过程演化链**（地貌变老、生长） | 地理 | 一块可变形大地形 + 阶段档位 | 阶段/时间轴 slider（离散档+字典刻度） |
| **机制链**（信号传递、因果顺序） | 生物 | 多尺度子场景（并排 or 放大窗） | 参数 slider（浓度/条件）+ 大量 watch 步 |
| **因果链**（原因→结果） | 物理 | 剖面台/装置台 + 矢量箭头场 | 单参数 slider（温差/电压/频率） |
| **矛盾-折中链**（速率vs平衡） | 化工 | 厂区流程（anchor 飞行取景） | 参数 slider 带 band（教材达标区间） |
| **变量-实验链**（自变量→因变量） | 化/生实验 | 实验台多站位 + 对照组 | 仪器 slider（T/pH）+ 多档开关 |

## 1. 时间的三种表达（按成本从低到高选）

1. **折叠成函数**（最省）：无时间轴，`u = u(ΔT)`，拖 slider 立即出结果。适合因果链课。
2. **做成参数**（中）：时间=档位 slider（万年/阶段/幼壮老年），`evaluate(S)` 仍纯函数。
   地理标准做法：预烘焙 N 套高度场，拖阶段时插值变形（限速平滑每秒最多 2.2 阶段差）。
3. **放慢成电影**（最贵）：内部时序 tick（1 生理 ms = 0.1 s 界面），脚本化波形+相位流。
   只有机理课（神经冲动）值得。

**默认选 1**；「零延迟交互」是这套课件的体验底线——除确需时序的 ODE 外，模型一律无记忆。

## 2. 各学科模板要点

### 化学·实验台型（钠/滴定/速率…）
- 尺度：米制实物。台面 y=0，地面 −0.78；站位 x=[−0.36,−0.12,0.12,0.36]；每步 cam.box 特写。
- 站位即知识链环节的「实证现场」，每站常配**对照组**（泡煤油的钠 vs 敞口的钠；滴酚酞 vs 没滴的）。
- model：速率用 exp(−kt)（对照工况差 45 倍速率这类「可感差异」）、pH 用对数式、
  风险分段线性（保证「对的方法永远风险低」的排序不变）。
- 特效：双层 shader 火焰（外焰+内芯+光晕，双频 sin 抖动）、气泡相位循环、
  InstancedMesh 颗粒流（from→to 重力抛物线）、cube↔sphere 形变（熔化）、canvas 计数牌。

### 化学·工业流程型（合成氨/硫酸/氯碱…）
- 尺度：厂区百米级，根节点 x/z 压缩 0.55；anchor 表 `{x,label,focus,dist,box,r}` 飞行取景；
  前景（道路/卡车）随镜头重建；设备带位号铭牌（R-401…）。
- 步骤=按工艺流向逐工段回答「为什么需要你」，**破坏性体验**是核心教学法：
  关净化看触媒中毒（不可逆！）、切循环看利用率跳水、推温度越过教材带看风险抬头。
- model：教材数据表打底（表 2-2 直接进代码和图表 dots）→ 反演插值 → 二分解平衡 →
  动力学 × 烧结截断 × 配比形状函数 → `rate=min(反应器限,原料限)`；**标定法**保证读数可溯源。
- 事故系统（独有）：check-trip-countdown（3s 倒计时+estop 钳位）→ 爆炸全家桶 →
  复盘剧本（因果链+预防清单+教训）→ repair 复产。

### 地理（喀斯特/河流/大气…）
- 大地形三件套：**解析形态场**（锥峰/溶沟/洼地都是具名函数场，噪声只做质感）+
  **顶点色坡度着色** + **程序化地层侧壁**（「虚线=原地表」把侵蚀量画出来）。
- 水/气流：ribbon 河道 + canvas 流动纹理滚动（一切「流」的最低成本方案）；
  闭环粒子链（CatmullRom）收尾「环流」概念；参数化箭头群（长度∝量、方向随符号、可点击）。
- 等值面：圆盘顶点高斯挠曲 + 竖向夸张（18 倍，foot 声明）+ 逐步透明度聚焦。
- units 是**空间单元**（河段/左中右+高空近地面），camera 低 pitch（9–30°）近水平看剖面。

### 生物（神经/酶/transport…）
- 双尺度是标配：并排三子场景（纤维/膜片/突触）或 实验台嵌入放大圆窗。
- 膜片范本：磷脂层=头球+尾杆 InstancedMesh；通道=torus 环（阻断变灰熄灭）；
  离子=相位流实例球（兴奋时相位速度 ×8.5）；**电位=+/− 符号阵翻转**（抽象→可数）。
- 实验型（酶）：现象站→结构解释→规律综合三段式；`prep` 钩子按当前实验站切换主读数语义；
  成对步骤显式对照（高温不可逆 vs 低温可恢复，同 box、同开关不同档、expect 互指）。
- watch 步（安静观察 secs 秒）是生物节奏工具——过程放慢后「观察即任务」。

### 物理（光电效应/自感/布朗…）
- 装置写实（光电管/电源/电流表），场线/矢量箭头参数化；
  探索型 act：扫零点（custom ok 判定第一次读到 0.000）、换波长/阴极材料重扫、记录 3 行数据拟合。
- chart 是主角：多条曲线对比（不同光强/材料），「对照曲线常驻」=对照实验思想的 UI 化。

## 3. 中控台 = 因果链的仪表化

- **main = 链末端量**（风速/产率/活性/膜电位/起伏度），subs = 中间环节量 + **判断文本**
  （「冲淤平衡」「成石柱」这类文字判据也是副读数）。
- slider = 自变量；离散档位 slider（fmt 映射名字）当「阶段选择器」。
- chart 三种范式：**相图定位**（演化课：路径上的现在位置）、**滚动示波**（机理课：环形缓冲）、
  **规律曲线**（实验课：随参数实时变形 + 虚线基准 + band 教材区间）。
- 实验/化工专用增强：slider `band` 教材区间、`fill:"heat"` 温度渐变、多档开关 `states`、
  station 切换读数（prep 钩子）、risk 表、record 数据表。
- 原理现象课的评估闭环 = `hold + exam.ok` 即可，**不必配 risk/record**。

## 4. 考核步统一格式（hold 15s）+ 扰动四式

考核绝不引入新控件、没有新知识，考「会不会用前面所有的开关与读数」：

1. **自动事件**（最常用）：`events:[{at:5, set:{…}, toast}]`——汛期来了/抽走 Na⁺/抬温水温/
   换灭火器，学生必须在扰动后重新达标。
2. **隐含约束**：ok 里藏一个条件（必须白天 night!==true），expect 明说「夜晚无论多大都不算」。
3. **双任务并联**：两个条件同时满足（起伏最大 + 石钟乳石笋接上）。
4. **多变量达标**：T、pH、预处理三条件同时成立（enzyme）。

## 5. 数值可信度三级（foot.note 必填）

1. 教材有数值 → 直接用（标注页码）；
2. 教材无数值 → 用**真实公式**算并标「示意·按公式」（压高公式/Manning/Shields）；
3. 纯形态/示意 → 只给单位量级，标注「课件设定」。
   **尺度假象要声明**：竖直放大 5 倍/垂直×10/等压面夸大 18 倍/时程放慢——每课 foot.note
   都是「夸张倍数 + 示意范围」的诚实模板。

## 6. 特效手法速查（跨学科标准件）

| 相位粒子流（梯度驱动） | 神经冲动 | 扩散/渗透/迁移 |
| 参数化箭头群（长度∝量） | 热力环流 | 速度场/力场 |

## 7. 工程三件套（与内容同权重）

- `live()` 遥测：模型读数 + 视觉事实（颜色十六进制、计数、缩放、坐标）——测试断言 live() 而非截图。
- `dbg` 破坏钩子：把单个视觉贡献强制关掉/翻转（tintOff/fireOff/…），隔离变量验收。
- expect 里的数值断言：运行时不消费，是给验收测试钉模型输出用的契约值。
- 相机档位参考：micro size 0.8–3 / 实验台 1.6 / 沙盘 12–14 / 剖面台 22；fov 27–30；
  polar 上限 34°（剖面不许看底）～62°（自由环绕）。
